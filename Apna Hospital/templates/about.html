The pipeline

  1. Understand. Plain-language input is matched to symptoms using phrases, synonyms, typo tolerance and negation ("no fever" is ignored).
  2. Rank. A 300-tree random forest returns a score for every condition. We show the top three, not a single verdict.
  3. Ask. The system finds the symptoms that would best separate the leading candidates and offers them as one-tap follow-ups.
  4. Triage. Symptom severity weights plus a red-flag list (chest pain, slurred speech, one-sided weakness, coma, bleeding…) set an urgency level. Red flags override the model.
  5. Act. Precautions, diet, lifestyle, common treatments, the right specialist, a Maps link and a downloadable PDF.

Honest limits

  • The public Kaggle-style dataset has {{ '{:,}'.format(metrics.rows) }} rows but only {{ metrics.unique_rows }} distinct symptom patterns, and is cleanly separable. Cross-validated accuracy on de-duplicated rows is {{ (metrics.cv_accuracy*100)|round(1) }}%, which says more about the dataset than about real-world performance.
  • Real patients present messier symptoms and many more conditions than the {{ n_diseases }} modelled here.
  • We found and fixed a one-row shift in the source medication table that had given Heart attack the treatments for varicose veins, among others.
  • Nothing here is a diagnosis. Treatments listed are common options a doctor may consider.
